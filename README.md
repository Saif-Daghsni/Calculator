# 🖥️ MERN Calculator – Learning Project  

This is a **simple calculator application** built with the **MERN stack** (MongoDB, Express, React, Node.js) as my first project to learn full-stack development.  

---

## 📱 Features  

- Perform basic arithmetic operations: **addition, subtraction, multiplication, division**  
- **Responsive UI** built with React  
- **Backend** powered by Node.js and Express (no database required)  
- Serves as a **learning project** to understand the flow of a MERN application  

---

## ⚙️ Objective  

- Gain hands-on experience with **React** and **Node.js/Express**  
- Understand how a MERN app is structured, even without persistent data  
- Build a foundation for more advanced full-stack projects
